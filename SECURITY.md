# Security policy

## Supported versions

Security fixes are made against the latest release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's private
vulnerability reporting form under the repository's **Security** tab. Include the
affected version, reproduction steps, and impact. If the form is unavailable,
contact the maintainer through the email address in the repository's Git commit
metadata.

The installer is unsigned. Review its source and compare its SHA256 checksum with
the value in the release notes before running it.
